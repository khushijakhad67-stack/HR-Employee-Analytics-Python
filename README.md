# HR Employee Analytics — Python Project

A beginner-friendly HR data analysis project using Python, Pandas and Matplotlib.

## What this project analyzes
- Total employees
- Average monthly salary
- Average age and experience
- Department-wise employee count
- Department-wise average salary
- Top 10 highest-paid employees
- City-wise employee distribution
- Gender distribution
- Experience vs salary visualization

## Tools
Python | Pandas | Matplotlib | CSV

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Skills demonstrated
Data handling, Pandas, GroupBy, sorting, aggregation, CSV files, data visualization and basic HR analytics.
